## Overview

Developed a full-stack autonomous vehicle summoning system featuring path generation, obstacle detection, self-parking and a mobile user interface, fully integrated into the ROS-based GEMstack software stack and conduct in-vehicle tests on GEMe2.

## Key Contributions

- **Motion Planning**: Implemented motion planning for collision-free path generation using RRT* and Reeds–Shepp curves for autonomous parking and summoning maneuvers

- **Perception Pipeline**: Integrated real-time obstacle detection using YOLO-based perception pipeline for enhanced safety and situational awareness, utilizing onboard cameras and LiDAR

- **Mobile Interface**: Developed a mobile application enabling users to specify pick-up and drop-off locations, interfacing with the autonomous vehicle system (GEMstack)

## Technical Stack

- **Languages**: Python, ROS
- **Algorithms**: RRT*, Reeds-Shepp curves, YOLO
- **Hardware**: Onboard cameras, LiDAR
- **Integration**: GEMstack software stack, PACMOD systems

## Project Timeline

**Duration**: January 2024 - December 2024

This project was developed as part of coursework and successfully integrated into the GEMstack platform for real-world testing on the GEM e2 vehicle.
